# E-Commerce Sales & Logistics Dashboard

An interactive Power BI dashboard designed to analyze net sales performance, regional revenue distributions, and shipping efficiency.

![Dashboard Preview](Screenshot%202026-09-01%20185419.png)

## 📌 Business Overview & Key Metrics
- **Total Net Sales:** $1.28M across key retail and wholesale customer segments.
- **Order Volume:** 487 total fulfilled and pending orders.
- **Return Rate Analysis:** Tracked order returns (25.46%) to identify product/logistics issues.
- **Shipping Delays:** Evaluated average shipping delay (6.24 days) for operational optimization.

## 📊 Dashboard Visual Insights
1. **Regional Performance:** East and North regions generated the highest net sales volume.
2. **Order Return Breakdown:** Donut chart visualization comparing valid vs. returned orders.
3. **Interactive Slicers:** Date range dynamic slider and Customer Type selector (Retail vs. Wholesale).

## 🛠️ Tech Stack & Tools
- **Tool:** Power BI Desktop
- **Data Transformations:** Power Query
- **Calculations:** DAX Measures
